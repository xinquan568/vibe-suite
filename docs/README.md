# `docs/` — Documentation

[`adr/`](adr/) — the live architecture decision records — plus contributor docs and
[`discussion/`](discussion/), the planning records this project was built from. Discussion documents
are historical: where they disagree with current configuration, current configuration wins, and where
a decision postdates them, their banner cites the ADR that settles it.

[`exit-codes.md`](exit-codes.md) — every shipped program's exit codes: the registry `tests/test_exit_codes.py` checks each program's header against.
